Leo’s ISEB NVR Challenge Pack

Six interactive non-verbal reasoning tests designed for high-level ISEB Common Pre-Test practice. Each test has 20 questions, a 30-minute practice timer, instant marking, a practice SAS estimate, and explanations for every question.

Important: ISEB’s live test is adaptive and its official age-standardised score uses proprietary calibration against an independent-school sample. The “Practice SAS” here is therefore an estimate for tracking practice only, not an official or predicted ISEB score. Leo’s birth month is set to November 2015.
